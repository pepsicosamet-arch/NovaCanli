# Tanıtım filmi kaynakları

`docs/NOVA-Canli-Tanitim.mp4` bu dosyalarla üretildi:

- `clips.html` — demo görüntüler (manzara ve neon yarış) kare kare çizilir.
- `capture.py` — NOVA Canlı'yı tarayıcıda açar, kaynakları ekler, geçiş/grafik/tekrar yapıp program çıktısını uygulamanın kendi kaydıyla alır, arayüz ekran görüntüleri çeker.
- `promo.html` — grafik sahneler (açılış, kelimeler, arayüz, platformlar, özellikler, kapanış). `?s=sahne` ile açılır, `render(t)` ile her kare çizilir.
- `frames.py` — bir sahneyi 30 fps MP4'e kodlar.
- `music.py` — 120 BPM özgün müzik (Am-F-C-G) üretir.
